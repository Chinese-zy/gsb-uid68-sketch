# 平面草图

从零开始。只用浏览器自带能力，不要装第三方库。做好后直接打开页面。

直接双击 `index.html`（或 `open index.html`）即可运行，无需构建、无第三方依赖。

## 文件
- `index.html` — 页面与工具栏
- `solver.js` — 纯函数约束求解器（阻尼高斯-牛顿，最多 50 轮，不会卡死页面）
- `app.js` — Canvas 绘制、坐标变换、命中测试、交互、撤销重做、示例
- `test-solver.js` — Node 冒烟测试：`node test-solver.js`

## 功能
- 图元：点、线段、圆（圆心是点）
- 约束：重合、固定距离、水平、竖直、点圆相切、锚定点
- 拖点时其余点按约束联动；解不出来时冲突约束在图上和侧栏标红
- 滚轮以光标为中心缩放，空格/中键/平移工具平移；命中测试始终在图纸坐标系做
- 撤销/重做按用户操作（一次拖拽、一次建约束各算一步）：Cmd/Ctrl+Z、Cmd/Ctrl+Shift+Z
- 顶部两个示例：「四连杆」可拖着玩，「冲突」演示无解时标红
